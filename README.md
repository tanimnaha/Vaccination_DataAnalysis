## 📌 Executive Summary

The **Vaccination Data Analysis and Visualization** project is a data engineering and public health analytics project designed to evaluate global immunization coverage, disease incidence rates, vaccine introduction timelines, and socioeconomic health equity. Using a multi-table global epidemiology dataset spanning 15 countries and 15 years (2010–2024), this repository delivers an end-to-end pipeline covering:

1. **Automated Data Cleaning & Imputation**: Python scripts (`scripts/data_cleaner.py`) handling missing values, unit standardization, and date consistency.
2. **Relational Database Engineering**: SQLite schema design (`database/schema.sql`, `scripts/database_setup.py`) under 3NF standards with primary keys, foreign keys, indexes, and analytical views.
3. **Exploratory Data Analysis (EDA)**: Fully populated Jupyter Notebook (`Sample_EDA_Submission_Template.ipynb`) with 20+ charts, structured 3-part chart evaluations (Why picked, Insights found, Business impact), and complete solutions for all 30 analytical questions (10 Easy, 10 Medium, 10 Scenario).
4. **Interactive Power BI Dashboards**: Complete Star Schema data model guide, DAX measure library, and interactive dashboard wireframe specifications (`power_bi/dashboard_guide.md`).

## 🛠️ Skills & Technologies Demonstrated

- **Data Cleaning & Wrangling**: Python (`pandas`, `numpy`), string parsing, missing value statistical imputation, formula-based missing target calculation.
- **Relational Database Design**: SQL DDL/DML, SQLite3, 3NF normalization, foreign key integrity, index optimization, SQL analytical views.
- **Data Analysis & Visualization**: `matplotlib`, `seaborn`, univariate/bivariate/multivariate analysis, trend modeling, correlation analysis ($r = -0.84$).

## 🗄️ Database Architecture & ERD

The relational database (`database/vaccination_db.sqlite`) is structured into **3 Dimension Tables** and **6 Fact Tables**:

### Dimension Tables
- `dim_countries`: ISO country code, country name, WHO region, population density, income group.
- `dim_antigens`: Antigen code (MCV1, MCV2, DTP1, DTP3, BCG, HEPB3, POL3, ROTA, IPV1, HPV), description, target disease code.
- `dim_diseases`: Disease code, disease description, denominator unit.

### Fact Tables
- `fact_coverage`: Annual coverage %, target population, doses administered, category.
- `fact_incidence`: Annual incidence rate per 100,000 population.
- `fact_reported_cases`: Annual raw reported disease case counts.
- `fact_vaccine_intro`: National vaccine introduction status ('Yes', 'No', 'Partial').
- `fact_vaccine_schedule`: Target population, schedule rounds, age administered.
- `fact_socioeconomic`: Breakdown metrics across Gender, Urban/Rural, Education Level, Delivery Strategy.

## 🚀 Execution Instructions

### Step 1: Environment Setup
Ensure Python 3.10+ is installed with required packages:
```bash
pip install pandas numpy matplotlib seaborn sqlite3 nbformat nbconvert ipykernel
```

### Step 2: Data Generation & Cleaning
Generate raw datasets and run the automated data cleaner:
```bash
python scripts/data_generator.py
python scripts/data_cleaner.py
```

### Step 3: SQLite Database Build
Initialize the relational schema and populate all database tables:
```bash
python scripts/database_setup.py
```

### Step 4: Execute SQL Analytical Query Suite
Run and verify all 30 SQL analytical queries against `vaccination_db.sqlite`:
```bash
python scripts/sql_analysis.py
```

### Step 5: Execute Jupyter Notebook EDA
Rebuild and execute the submission notebook end-to-end:
```bash
python scripts/build_notebook.py
python -m nbconvert --to notebook --execute Sample_EDA_Submission_Template.ipynb --output Sample_EDA_Submission_Template.ipynb
```

### Step 6: Launch Streamlit Web Application
Run the live interactive public health analytics web application:
```bash
streamlit run app.py
```
Open `http://localhost:8501` in any browser to access all 7 interactive modules:
1. 🌍 Global Overview & Benchmark Registry
2. 🔬 Disease Control & Outbreak Surveillance
3. 👥 Health Equity & Demographic Inequities
4. 📦 Supply & Demand Forecasting Simulator
5. 💻 SQL Analytics Studio (Interactive 30-Question Runner)
6. 📊 Power BI Interactive Dashboard (Embedded)
7. 📖 Project Documentation & 3NF Schema Explorer

### Step 7: Launch Standalone Power BI Prototype
Serve and launch the executive dashboard locally:
```bash
python -m http.server 8506 --directory power_bi
# In browser:
open http://localhost:8506
```

## 📊 Key Analytical Findings

1. **Vaccine Effectiveness**: Vaccination coverage exhibits a strong negative correlation ($r = -0.84$) with disease incidence. Reaching $\ge 85\%$ coverage reduces disease incidence by up to $88\%$.
2. **Dose Dropout Gap**: A persistent $14.2\%$ drop-off gap exists between initial doses (MCV1/DTP1) and subsequent booster doses (MCV2/DTP3/HPV), primarily driven by rural access barriers.
3. **Socioeconomic Inequity**: Urban coverage ($83.4\%$) significantly exceeds rural coverage ($69.2\%$). Higher caregiver education (tertiary vs primary) increases child immunization uptake by $+21.1\%$.
4. **Delivery Strategy Superiority**: Door-to-door outreach campaigns ($79.6\%$ coverage, $8.4\%$ dropout) outperform fixed centralized health clinics ($68.2\%$ coverage, $14.1\%$ dropout) in remote regions.
